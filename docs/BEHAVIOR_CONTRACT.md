# Davora Behavior Contract

This document is the refactor regression contract. It describes behavior, not current implementation structure. Each migrated slice must keep the listed evidence green and add automated coverage for its listed gap before retiring the old path.

Wave 4 convergence on 2026-09-01 resolves every contract ID to one live executable title and passes the focused authority/ownership/compatibility matrix 23/23, full web/Worker/shared suites, Chromium 185 runnable cases, screenshots 45 runnable captures, PWA 6/6, Worker dry-run, and constrained real-Nextcloud validation. The source-to-test manifest is `.tmp/agent-artifacts/worker/wave1-behavior-authority-20260831/manifest.md`; final convergence evidence is `.tmp/wave4/2026-09-01-final/`. No contract row was removed to make the refactor pass.

## Evidence levels

- **Model/unit:** pure rule, reducer, component, or adapter behavior.
- **Browser:** user-visible behavior and browser lifecycle through Playwright.
- **PWA:** install, service-worker, update, and offline-shell behavior.
- **Real backend:** Worker-to-Nextcloud behavior constrained to `.davora-agent-test`.
- **Visual:** isolated screenshot capture and automated geometry/state assertions; manual inspection is reserved for qualities that cannot be asserted reliably.

## Wake-lock lifecycle exception — Phase 8 Gate 2

`useScreenWakeLock` owns the current sentinel and its release-listener disposer as one identity-checked unit. Manual release, hidden/disabled transitions, external release, release rejection, replacement, and unmount dispose the current listener synchronously and release at most once. A pending rejection publishes `denied` only for a current mounted visible desired supported request; hidden rejection remains on the already projected released state. An obsolete sentinel callback cannot clear or alter a replacement sentinel. Late success after disable, hidden visibility, supersession, or unmount releases once without installing a listener or publishing `active`.

Verified by the unchanged 19-test lifecycle characterization (19/19 across default, repeat, no-file, and shuffle), the focused 33-test wake-lock scope, deterministic race ports, and the existing desktop/mobile local/mock browser contract. Evidence: `.tmp/agent-artifacts/worker/wake-lock-lifecycle-gate2-20260824T232547Z/`; independent approval: `.tmp/agent-artifacts/expert/20260825T001000Z-wake-lock-gate2-post-rereview.md`. This exception records lifecycle correctness only; it does not change public wake-lock state, reason ordering, browser adapter behavior, or broader Phase 8/9/release boundaries.
